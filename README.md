# 100 Days of DSA

One DSA problem every day. GATE 2027 prep + competitive programming practice.

Started: 2 Oct 2026

## Run any solution

```bash
python3 day-014/solution.py
```

Each `day-NNN/` folder is self-contained: `solution.py` runs standalone and
prints its own self-test results.

## Structure

```
day-001/
  solution.py   # working solution, clean and commented
  README.md     # problem statement, approach, complexity
```
