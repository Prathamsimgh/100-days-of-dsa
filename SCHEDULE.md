# 100-Day DSA Schedule

Roughly mapped to the GATE CS syllabus, ordered easy → hard.

| Days | Topic | Focus |
|------|-------|-------|
| 1–12 | Arrays | Two pointers, sliding window, prefix sums, sorting, kadane |
| 13–20 | Strings | Anagrams, pattern matching, KMP / Rabin-Karp, palindromes |
| 21–28 | Linked Lists | Reversal, cycle detection, merge, intersection |
| 29–34 | Stacks & Queues | Monotonic stack, next greater element, deque, LRU |
| 35–44 | Trees & BST | Traversals, LCA, diameter, BST ops, serialization |
| 45–52 | Heaps | K largest/smallest, merge k lists, median stream |
| 53–62 | Graphs | BFS/DFS, Dijkstra, MST, topological sort, union-find |
| 63–74 | Dynamic Programming | 1D, 2D grids, knapsack, LIS, subsequences, partitions |
| 75–80 | Greedy | Intervals, scheduling, Huffman-style picks |
| 81–86 | Backtracking | Permutations, N-queens, sudoku, subsets |
| 87–92 | Bit Manipulation & Math | XOR tricks, power of two, sieve, gcd, modular arithmetic |
| 93–100 | Mixed revision | GATE-style mocks, timed sets, weak-topic redo |

No repeated problems. If a day is missed, pick up the next topic — don't backfill.
